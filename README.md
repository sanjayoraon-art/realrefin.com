# RealRefin.com - Rental Yield Calculator

A high-converting, responsive, and SEO-optimized **Rental Yield Calculator** specifically targeting real estate investors in the **United States (US)**, **United Kingdom (UK)**, and **Australia (AU)**.

## Features
- **Real-time Calculations**: Gross Rental Yield, Net Rental Yield, Annual Net Cash Flow, and Monthly Breakdown.
- **Multi-Currency Support**: Interactive toggle for `$ (USD)`, `£ (GBP)`, and `A$ (AUD)`.
- **Rent Frequency Toggle**: Calculate using Monthly or Weekly rental inputs.
- **Expense Breakdown**: Deduct property management fees, property taxes/council rates, insurance, maintenance reserves, and other recurring operating costs.
- **Dynamic Rating System**: Visual performance badge indicating High Yield, Solid Yield, or Low Yield/Caution.
- **SEO & Schema Optimized**: Includes comprehensive 1,000+ words investment guide and JSON-LD structured data (`WebApplication` & `FAQPage`).

## Local Development
Run the local server:
```bash
node server.js
```
Then navigate to `http://localhost:3000/`.
